# PIYOL' — сайт-каталог корейской косметики: спецификация

Дата: 2026-10-13 · Статус: на согласовании · Документ-обсуждение: https://claude.ai/code/artifact/61c60fa4-0e34-4c87-8f60-593c1445b9ab

## 1. Цель

Новый сайт-каталог для магазина PIYOL' (Алматы, ТРЦ Forum). Клиент быстро находит средство,
собирает корзину и одним нажатием отправляет заказ менеджеру в WhatsApp. Менеджер сам ведёт
товары и цены в Google Таблице — без админки и без участия разработчика.

**Критерии успеха**
1. С телефона клиент от главной до отправленного в WhatsApp заказа доходит за ≤ 4 нажатия.
2. Сообщение в WhatsApp уже содержит товары, количество, сумму, имя и способ получения.
3. Менеджер меняет цену в таблице — на сайте она обновляется не позже чем через 5 минут.
4. Lighthouse (мобильный) ≥ 90 по Performance и Accessibility на главной и в каталоге.

**Вне рамок (сейчас):** онлайн-оплата, личный кабинет, отзывы, мультиязычность, админка,
перенос домена piyolbeauty.kz (решим перед запуском).

## 2. Решения

| Тема | Решение |
| --- | --- |
| Заказ | Корзина в браузере → сообщение в WhatsApp (`wa.me`), без оплаты |
| Источник товаров | Google Таблица, опубликованная как CSV; сайт перечитывает её раз в 5 минут |
| Стартовые данные | Переносим товары с piyolbeauty.kz в таблицу |
| Стиль | Новый премиальный вид: светлые пастельные тона, много воздуха, акцент на фото |
| Хостинг | Vercel, репозиторий `ashimbekovd-dev/test` (позже переименуем в `piyol`) |
| WhatsApp заказов | `+77080503518` — по умолчанию, в одной настройке `NEXT_PUBLIC_WHATSAPP` |

## 3. Стек

- **Next.js (App Router) + TypeScript**, рендеринг на сервере с ISR (`revalidate = 300`).
- **Tailwind CSS** для вёрстки; шрифты через `next/font`.
- **Корзина:** клиентское состояние в React-контексте, сохраняется в `localStorage`
  (с защитой: если хранилище недоступно, корзина живёт до перезагрузки).
- **Тесты:** Vitest для логики (разбор CSV, корзина, текст сообщения); Playwright-скриншоты
  ключевых страниц для визуальной проверки.
- Supabase и Resend на этом этапе **не используются** (YAGNI); понадобятся для заявок/отзывов позже.

## 4. Данные: Google Таблица

Один лист «Товары», первая строка — заголовки. Сайт читает CSV-ссылку из переменной
`PRODUCTS_CSV_URL`.

| Колонка | Тип | Обяз. | Пример / правило |
| --- | --- | --- | --- |
| `sku` | текст | да | `SC-PBC-50` — уникальный, используется в URL |
| `name` | текст | да | `Probiotics Barrier Cream` |
| `name_ru` | текст | нет | `Барьерный крем с пробиотиками` |
| `brand` | текст | да | `Scinic` |
| `category` | текст | да | одна из категорий (см. ниже) |
| `price` | число, ₸ | да | `13490` (пробелы и «₸» допускаются, отбрасываются) |
| `old_price` | число, ₸ | нет | заполнено и > `price` → показываем скидку |
| `volume` | текст | нет | `50 мл` |
| `description` | текст | нет | абзацы разделяются пустой строкой |
| `how_to_use` | текст | нет | |
| `images` | URL через `\|` или перенос | да | первая — обложка |
| `hit` | да/нет | нет | `да` → блок «Хиты» на главной |
| `in_stock` | да/нет | нет | `нет` → товар скрыт; пусто = в наличии |

**Категории (стартовый набор, как на текущем сайте):** Очищение, Увлажнение,
Дополнительный уход, Космецевтика PIYOL', Линии ухода PIYOL', Готовые наборы,
Уход за волосами, Макияж, Уход за телом, Миниатюры, Подарочные наборы.
Категории берутся из данных: новая категория в таблице появляется на сайте сама.

**Обработка ошибок данных**
- Строка без `sku`, `name`, `price` или `images` пропускается и пишется в лог сервера.
- Дубликат `sku` — берём первую строку, остальные в лог.
- Таблица недоступна → сайт показывает последнюю успешно загруженную версию (кэш ISR);
  при самой первой сборке без данных — сборка падает с понятной ошибкой.

**Фото.** На старте — ссылки на фото с piyolbeauty.kz. Риск: при отключении старого сайта
фото пропадут. До публичного запуска переносим фото в своё хранилище (отдельная задача).
Домены картинок разрешаются в `next.config` для `next/image`.

## 5. Страницы

| URL | Содержание |
| --- | --- |
| `/` | Первый экран со слоганом «Уход, в который можно влюбиться», плитки категорий, «Хиты», «Скидки», блок о бренде, магазин в ТРЦ Forum |
| `/catalog` | Сетка товаров; фильтры категория и бренд, поиск по названию (EN/RU), сортировка: по умолчанию / цена ↑ / цена ↓. Состояние фильтров в URL (`?category=…&brand=…&q=…&sort=…`) |
| `/product/[sku]` | Галерея, бренд, название, объём, цена/скидка, описание, способ применения, «В корзину», «Заказать в WhatsApp» (только этот товар), 4 похожих из той же категории |
| `/cart` | Позиции с количеством (± и удаление), итог; форма: имя (обяз.), способ получения — самовывоз из ТРЦ Forum / доставка (тогда адрес, обяз.), комментарий. Кнопка «Отправить заказ в WhatsApp» |
| `/about` | О бренде PIYOL' и брендах-партнёрах |
| `/delivery` | Самовывоз, доставка по Алматы и Казахстану, оплата, возврат — тексты с текущего сайта |
| `/contacts` | Адрес, карта, часы работы 10:00–22:00, телефоны, WhatsApp, Instagram, Telegram |

Общие элементы: шапка (лого, меню, поиск, иконка корзины со счётчиком), подвал (контакты,
соцсети, ссылки), плавающая кнопка WhatsApp на мобильном. Несуществующий `sku` → 404.

## 6. Корзина и сообщение в WhatsApp

- Корзина хранит `sku` и количество; цены и названия всегда берутся из актуальных данных.
  Если товара больше нет в таблице или он не в наличии, позиция помечается и не уходит в заказ.
- Количество 1–20 на позицию.
- Текст сообщения (собирается чистой функцией, покрыт тестами):

```
Здравствуйте! Заказ с сайта PIYOL':
1) Probiotics Barrier Cream — Scinic, 50 мл — 1 шт × 13 490 ₸
2) …
Итого: 26 980 ₸
Имя: Айгерим
Получение: самовывоз (ТРЦ Forum)
Комментарий: …
```

- Ссылка: `https://wa.me/<номер>?text=<encodeURIComponent(текст)>`, открывается в новой вкладке.
- После отправки корзина **не очищается** автоматически (клиент мог не дойти до чата);
  есть кнопка «Очистить корзину».

## 7. Дизайн

- Палитра: тёплый молочный фон, пудрово-розовый и шалфейный акценты, глубокий графитовый текст.
- Типографика: выразительный шрифт с засечками для заголовков, чистый гротеск для текста
  (оба с кириллицей).
- Карточки без рамок, фото на светлой подложке 4:5, мягкие скругления, тонкие анимации наведения.
- Mobile-first: сетка 2 колонки на телефоне, 3–4 на десктопе. Боковые отступы ≥ 16 px.
- Лого PIYOL' — с текущего сайта.

## 8. Перенос данных с piyolbeauty.kz

1. Собрать список товаров по разделам каталога текущего сайта: название, бренд, цена,
   старая цена, объём, описание, способ применения, ссылки на фото.
2. Сохранить в `data/products.csv` в репозитории (ровно в формате раздела 4).
3. Создать Google Таблицу из этого CSV на Google Drive пользователя; пользователь публикует
   её («Файл → Поделиться → Опубликовать в интернете → CSV») и присылает ссылку.
4. Пока ссылки нет, сайт читает `data/products.csv` (тот же парсер) — разработка не блокируется.

## 9. Проверка

- Vitest: парсер CSV (цены с пробелами/₸, `да/нет`, несколько фото, пропуск битых строк,
  дубли), корзина (добавление, лимиты, пропавший товар), текст WhatsApp-сообщения.
- `next build` без ошибок; Lighthouse на `/` и `/catalog`.
- Скриншоты Playwright главной, каталога, товара и корзины на 390 px и 1440 px — визуальная
  проверка перед показом.
- Ручная проверка: изменить цену в таблице → через ≤ 5 мин видна на сайте.
